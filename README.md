# burdenline

Drill and blast operations for hard rock quarries.

The system carries a shot from the face survey through hole layout, charge design,
initiation timing, the vibration and airblast the timing implies, the explosives
drawn from the magazine to load it, the clearance that has to hold before it is
fired, and the reconciliation afterwards.

## Running it

```
npm install
npm test
npm start
```

Node 20.18 or newer on the 20 line. The store is SQLite, opened from the path in
`BURDENLINE_DB`.
